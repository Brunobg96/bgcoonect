BG CONNECT GESTOR — GERAR APK PELO CELULAR
===========================================

Este projeto já está configurado com:
- Pacote Android: com.bgconnect.gestor
- Firebase Cloud Messaging (FCM)
- google-services.json
- WebView para https://bgconnect.kinghost.net/admin.php
- Registro automático do token FCM após login
- Notificação de novo pedido com alta prioridade

COMO GERAR O APK PELO GITHUB (CELULAR)
--------------------------------------
1. Crie/acesse uma conta no GitHub.
2. Crie um repositório privado, por exemplo: bg-connect-gestor-android.
3. Envie TODO o conteúdo desta pasta para a raiz do repositório.
4. Abra a aba "Actions" do repositório.
5. Abra o workflow "Gerar APK BG CONNECT Gestor".
6. Toque em "Run workflow".
7. Aguarde o build terminar (ícone verde).
8. Abra a execução concluída.
9. Em "Artifacts", baixe "BG-CONNECT-Gestor-APK".
10. Extraia o ZIP baixado. Dentro estará app-debug.apk.
11. Instale o APK no Android e permita notificações.

TESTE DE PUSH
-------------
1. Instale o APK no aparelho do proprietário.
2. Abra o app.
3. Permita notificações quando solicitado.
4. Faça login no painel da loja.
5. Aguarde alguns segundos na primeira abertura após login.
6. Faça um novo pedido em outro aparelho/aba.
7. O aparelho do gestor deve receber a notificação Push.

IMPORTANTE
----------
- O APK gerado por esse workflow é uma versão DEBUG assinada automaticamente,
  adequada para testes e instalação direta.
- Para distribuir oficialmente aos clientes/proprietários ou publicar na Play Store,
  gere depois um APK/AAB RELEASE com uma chave de assinatura própria.
- Não coloque a chave privada firebase-service-account do SERVIDOR dentro do app Android.
  O app precisa apenas do google-services.json, que já está incluído.
