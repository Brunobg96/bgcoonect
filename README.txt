BG CONNECT Gestor

URL inicial: https://bgconnect.kinghost.net/admin.php
Pacote Android: com.bgconnect.gestor

Este projeto é um aplicativo Android WebView para o BG CONNECT.
Abra a pasta no Android Studio, aguarde o Gradle sincronizar e use Build > Build APK(s).

Observação: notificações enquanto o aplicativo estiver totalmente fechado exigem integração Push (FCM), que não está incluída nesta primeira embalagem WebView.
